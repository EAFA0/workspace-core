# Biz-Test Contract

本目录保存业务规则的可重复执行表达。

## 写回条件

一个 case 同时满足以下条件时写入：

- 覆盖关键业务规则、迁移模式或高风险边界；
- 未来需要重复执行；
- 输入、前置条件和通过标准可以稳定表达。

一次性排查命令、纯日志查询和临时数据不进入 Biz-Test。

## 目录结构

```text
biz-tests/<slug>/
├── README.md
├── test_*.py / test_*.sh
├── scripts/
└── fixtures/
```

## 领域 README

每个领域目录必须说明：

- 关联业务规则、feature 或需求；
- 覆盖目标；
- 环境和前置条件；
- 怎么运行；
- 怎么判定通过；
- 每个 case 对应的规则或风险点。

## 可执行要求

1. 每条测试可独立运行。
2. 通过条件由 exit code、明确字段或稳定输出判断。
3. 失败保留请求、响应、错误输出和环境信息。
4. 大段数据进入 fixture。
5. 凭证和个人环境状态不进入仓库。
