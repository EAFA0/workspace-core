# Architecture Contract

本目录只承载跨工具、跨项目稳定成立的标准，不记录当前实现状态或阶段计划。

## 内容边界

- 描述"是什么、必须满足什么"，不写当前落地状态、具体调度频率或历史修复过程。
- 不包含具体代理角色、委派步骤、CLI 选择、调度器或 hook 实现。
- 标准层不写"待启用"计划或阶段目标。

## 命名与结构

- 文件名：`<编号>-<主题>.md`，编号按标准建立顺序递增。
- 每份标准自包含一个稳定主题，不交叉复述其他标准的正文。
- 标准之间通过链接引用，不复制对方结论。
